#### CPU
1. 성능과 발열, 소비전력
    * 동작 주파수를 올려 연산 능력을 올렸지만, 발열과 소비전력도 커져 억제하는 방향으로 진화

2. 용어
- 소켓 수 : cpu 개수
- 코어 수 : 계산 부분
- 스레드 수 : 하나의 코어에서 동시에 처리할 수 있는 연산 수
- 캐시 : cpu와 메모리 사이의 고속 저장 장치
- 하이퍼 스레딩 : 하나의 코어로 두개 처리 실행
- 터보 부스트 기술 : cpu 속도를 자동으로 기준클럭보다 빠르게 동작시키는 기술

#### 메모리
- System Memory(DDR5) : cpu가 사용하는 주기억장치
- GPU Memory(HBM) : GPU가 사용하는 고대역폭 메모리
- Cache(SRAM) : CPU/GPU 내부의 매우 빠른 메모리
- Storage(SSD/NVMe) : 장기 데이터 저장
- Swap : RAM 부족 시 사용하는 저장장치 영역
